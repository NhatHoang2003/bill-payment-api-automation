# Bill Payment API Automation

API automation testing project for the Bill Payment REST API using Playwright and TypeScript.

The project is designed to demonstrate real-world API automation practices including authentication testing, data-driven testing, request/response validation, service-layer architecture, environment configuration, and CI execution with GitHub Actions.

---

## Tech Stack

- **Language:** TypeScript
- **Test Framework:** Playwright Test
- **API Client:** Playwright APIRequestContext
- **Runtime:** Node.js
- **Package Manager:** npm
- **CI/CD:** GitHub Actions
- **API Documentation:** OpenAPI 3.0 / Swagger

---

## Project Overview

The Bill Payment API is a RESTful API designed for API automation practice.

The API provides functionality related to:

- Authentication
- OAuth2 token management
- Users
- Billers
- Bills
- Payments
- Payment methods
- Addresses
- File uploads

This automation project focuses on validating API behavior from an end-to-end API consumer perspective.
